# Policy: Data Security & Access Control
Document ID: POLICY-IT-007
Owner: IT Security
Last Updated: 2026-05-20
Status: Active

## Purpose
Defines minimum data security standards for handling company and customer
data.

## Classification Levels
- **Public**: marketing material, published docs. No restrictions.
- **Internal**: SOPs, internal wikis, meeting notes. Employees only.
- **Confidential**: customer data, financials, contracts. Named access only,
  logged.
- **Restricted**: credentials, encryption keys, PII bulk exports. Requires
  Security team sign-off per access, time-boxed to 7 days.

## Access Control Rules
1. All Confidential and Restricted data access requires MFA.
2. Access to Restricted data is granted via a ticket in the Security Access
   Portal, approved by the data owner and IT Security.
3. Any suspected data exposure must be reported to security@company within
   1 hour of discovery (see Incident Response Runbook).
4. Laptops must have full-disk encryption and auto-lock after 5 minutes of
   inactivity.

## Vendor Access
Third-party vendors requesting access to Internal or higher data require a
signed Data Processing Agreement, reviewed by Legal and IT Security jointly.
